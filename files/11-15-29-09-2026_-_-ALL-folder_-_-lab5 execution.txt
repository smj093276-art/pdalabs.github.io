 ## 2\. Create `CleanDataUDF.java`

```
nano com/lab/pig/CleanDataUDF.java
```

 Paste:

```
package com.lab.pig;

import java.io.IOException;
import org.apache.pig.EvalFunc;
import org.apache.pig.data.Tuple;

public class CleanDataUDF extends EvalFunc<String> {

    @Override
    public String exec(Tuple input) throws IOException {

        if (input == null || input.size() == 0 || input.get(0) == null) {
            return null;
        }

        String str = (String) input.get(0);

        String cleaned = str
                .replaceAll("[^a-zA-Z0-9 ]", "")
                .trim()
                .toUpperCase();

        return cleaned.isEmpty() ? null : cleaned;
    }
}
```

 Save with **Ctrl+O**, Enter, then **Ctrl+X**.

 ## 7\. Create the Pig script

```
nano filter_script.pig
```

 Paste:

```
REGISTER 'CleanDataUDF.jar';

raw_data = LOAD '/user/hadoop/pig_input/raw_logs.csv'
    USING PigStorage(',')
    AS (id:int, message:chararray);

cleaned_tuples = FOREACH raw_data GENERATE
    id,
    com.lab.pig.CleanDataUDF(message) AS clean_msg;

filtered_data = FILTER cleaned_tuples BY clean_msg IS NOT NULL;

STORE filtered_data
    INTO '/user/hadoop/pig_output'
    USING PigStorage(',');
```

 Save and exit.

---

 ## 8\. Delete previous output

 Pig will fail if `/user/hadoop/pig_output` already exists.

 Run:

```
hdfs dfs -rm -r -f /user/hadoop/pig_output
```

---

 ## 9\. Execute the Pig program

 Now the important command:

```
pig -x mapreduce filter_script.pig
```

 Wait for the job to finish.

 You should eventually see something indicating the job completed successfully.

---

 ## 10\. View your output

 Run:

```
hdfs dfs -cat /user/hadoop/pig_output/*
```

 With the test input above, you should get:

```

2,PURCHASE COMPLETED SUCCESSFULLY
```

 The `@@@` record produces an empty string, which your UDF converts to `null`, and the `FILTER` removes it.
